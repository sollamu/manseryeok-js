## User
사주팔자 계산 (시주 포함)을 하고 싶다. 이 앱에서 어떻게 사용하나?

## Assistant
README에 이미 답이 다 있다. 이 라이브러리(`manseryeok-js`) 자체에서 `calculateSaju`로 시주까지 계산할 수 있다.

**사용법:**

```ts
import { calculateSaju } from '@fullstackfamily/manseryeok';

// 1990년 5월 15일 14시 30분생
const saju = calculateSaju(1990, 5, 15, 14, 30);

console.log(saju.yearPillar);   // 년주 (예: '경오')
console.log(saju.monthPillar);  // 월주
console.log(saju.dayPillar);    // 일주
console.log(saju.hourPillar);   // 시주 (예: '계미')
console.log(saju.isTimeCorrected);   // true
console.log(saju.correctedTime);     // { hour: 13, minute: 58 } — 진태양시 보정 결과
```

핵심 포인트:
- 시주는 기본적으로 **진태양시(True Solar Time) 보정**이 적용된다. 한국 표준자오선(135°)과 실제 출생지 경도 차이만큼 시간을 보정해서 시주를 계산한다.
- 기본 경도는 서울(127°)이며, 다른 지역이면 `options.longitude`로 지정:
  ```ts
  calculateSaju(1990, 5, 15, 14, 0, { longitude: 129 /* 부산 */ });
  ```
- 보정 없이 단순 계산하려면 `calculateSajuSimple(year, month, day, hour)` 사용.
- 실제 실행 예제는 `examples/06-saju-calculation.mjs`에 있고, 빌드 후 `node examples/06-saju-calculation.mjs`로 바로 돌려볼 수 있다.
